# Auto Claims Knowledge Base

Motor vehicle claims: policy, coverage, claim, incident, handling, money in and out.

An OTO pack in the insurance domain: the ontology `auto-claims` (release 3) under `ontology/`, the skill `start` that begins a project from it, and the views under `views/`. Install it in Claude Code from the registry's marketplace, or `oto pack add auto-claims` on a machine.

`oto pack check` validates it; `oto pack refresh` re-embeds the ontology when the registry holds a newer release; `oto pack publish --to <registry>` releases it.
