# How it is designed

The software-architecture pack's page in the product's studio (`place: design`): the systems and
their parts, what each offers and uses, the data it reads and writes, where it runs, the
requirement it meets, what it carries (a domain model, an agent: the pattern pages link here), the
decisions that shaped it and the risks to it, written as sentences from the knowledge base. The
questions of the architecture (`SA`) that are still open are listed at the bottom.
