# Where it runs

The platform binding's page in the product's studio (`place: runs`): the cloud and its accounts,
each environment (its region, console, logs and the infrastructure code that creates it), what
each part runs on and is built with, its secrets by name and where they are kept (never a value),
its pipelines, and who decided each choice: a named person, or the builder within limits and
confirmed. The binding's open questions (`PL`) are listed at the bottom: what an implementing agent
still lacks to build, deploy and test end to end.
