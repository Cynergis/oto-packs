# Engagement Knowledge Base

Engagements: scope, deliverables, governance, sessions, decisions and the work that follows.

An OTO pack in the professional-services domain: the ontology `professional-services` (release 2) under `ontology/`, the skill `start` that begins a project from it, and the views under `views/`. Install it in Claude Code from the registry's marketplace, or `oto pack add professional-services` on a machine.

`oto pack check` validates it; `oto pack refresh` re-embeds the ontology when the registry holds a newer release; `oto pack publish --to <registry>` releases it.
